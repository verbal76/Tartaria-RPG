# Tartaria Prima: Master Exploration and Salvage Registry

> Authored source for location interactables, loot detail, and hook flavour.
> Stored here so the rich descriptions survive even though the JSON catalog
> stores only the noun-cores. Pull from this when authoring container_loot
> entries, hook outcomes, area-search MATERIAL_LINES, or quest items.

The ingest pass on this file extracted noun-cores (single-word or short
phrase) into `app/data/locations/locations.json` `interactables` arrays.
The full descriptions below are the canonical source for what each item
"really is" when it surfaces in narration or loot.
